# 🖥️ Neural Network GUI

> Desktop app to build, train and test neural networks

![Python](https://img.shields.io/badge/Python-1f6feb?style=flat-square) ![Tkinter](https://img.shields.io/badge/Tkinter-1f6feb?style=flat-square) ![NumPy](https://img.shields.io/badge/NumPy-1f6feb?style=flat-square)

## 📌 Overview
A Tkinter application that lets you configure a neural network (layers, neurons, learning rate, epochs, activation), train it on a dataset and test it — no code required.

## ✨ Features
- Configure network architecture from the UI
- Choose activation function and hyperparameters
- Train and view accuracy
- Test on new samples

## 🛠️ Tech Stack
Python, Tkinter, NumPy

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python app.py
```
